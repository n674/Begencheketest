BEGENCHEKE PWA - Acode kurulum
1. ZIP dosyasini telefona indir ve cikar.
2. Acode ile BEGENCHEKE_PWA klasorundeki index.html dosyasini ac.
3. Acode onizleme ozelligiyle arayuzu gor.
4. iPhone'a ana ekran uygulamasi olarak eklemek icin klasorun tum dosyalarini HTTPS destekli bir web sunucusuna yukle.
5. iPhone Safari ile HTTPS adresini ac, Paylas > Ana Ekrana Ekle.

DIKKAT: Bu surum Android Java kodunun birebir calisan kopyasi degildir; tasarim ve temel ozellikler web icin yeniden yazildi. Android uygulamasindaki veriler otomatik tasinmaz. Veriler tarayicinin yerel depolamasinda saklanir. Onemli kayitlar icin Ayarlar > Yedek disa aktar secenegini kullan. PIN tarayicida sifreleme saglamaz. Gercek para islemleri icin profesyonel muhasebe sistemi yerine gecmez.
